# 0.3.7 release candidate

GitHub tag: `v0.3.7-rc.1`. Native plugin manifests: `0.3.7`.
This remains a candidate: authenticated Claude model-session verification is
blocked by the existing authentication problem. Do not claim production-verified
Claude automation or general real-vault retrieval accuracy.

## Changes

- Add local-only recall and validated 1-20 output limits; measure the actual
  production twenty-candidate pool instead of conflating it with top-ten output.
- Retain literal terms, add bounded mixed hash terminology and Korean-particle
  alternatives, and avoid duplicate synonym boosts.
- Prevent inferred hash matches from selecting unrelated hashtag compounds.
- Preserve rejection qualifiers, fenced-code examples and ATX section context;
  use full-source spans rather than crop-created word boundaries.
- Execute evaluation from a verified six-helper snapshot, reject module symlinks
  and missing fingerprints, and validate normalized question uniqueness/shapes.
- Add a cheap status-heading baseline and explicit limitations on synthetic
  development results. A previous live synthetic run had 94% first-hit accuracy
  for that baseline versus 100% for Jev; this is not real-vault evidence.
- Add bilingual README connection guidance and an existing-user update guide.

## Validation

- Local source suite: 104 passed, 9 platform skips, 0 failed.
- Extracted artifact: 55 passed, 1 skipped, 0 failed; native CLI installs, hashes,
  private-file exclusion and broken-helper controls passed.
- Fresh 0.3.7 Codex Windows unelevated smoke: task, automatic receipt and one
  session note verified on the second run. The first run completed the task but
  produced no automatic note; best-effort saving is not guaranteed every turn.
- Existing Jev synthetic requests and reranking worked; retrieval hardening was
  rechecked offline, without additional paid inference.
- Markdown handling is bounded ATX/fence support, not every extension.
- Independent real-vault accuracy, unanswerable cases, cross-platform agent E2E
  and Windows elevated operation remain unverified.

## Update

See [the existing-user guide](../UPDATING.md). Refresh the existing marketplace,
update the same plugin, reapply copied Codex hooks after reviewing the plan, and
start a new session. Do not delete notes or credentials and do not enable a
second marketplace copy. Jev remains optional and needs separate prior consent.

Agensi updates are uploaded and reviewed separately; a source release does not
establish that its latest ZIP is publicly downloadable there.
