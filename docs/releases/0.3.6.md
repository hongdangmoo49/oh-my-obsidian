# 0.3.6 release candidate

GitHub release tag: `v0.3.6-rc.1`. Native plugin manifests: `0.3.6`.
This is a candidate, not a production-verified Claude release. The GitHub
marketplace tracks main; an explicit plugin update installs this candidate.
No paid key, subscription or Jev connection is required for local memory.

## Changes

- Shared safe automatic saver for Claude and Codex, with approved legacy Claude
  SessionEnd migration that preserves other hooks and settings.
- Optional Jev recall reranking, masked Windows credential storage and separate
  project/vault external-text consent. Local search remains the default.
- Body-aware excerpts, rejection qualifiers, bounded long-paragraph windows,
  raw-text outbound safety checks and catalog/vault boundary protection.
- Free ZIP with root SKILL.md, individual file allowlist, standard ZIP paths,
  checksums, native manifests and isolated artifact regression controls.
- Automatic-save hook prompts describe helper behavior rather than imposing
  repository-wide Git policy.

## Updating

Use the agent's native plugin manager to update the existing GitHub marketplace
installation; do not add a duplicate Agensi installation. Reapply copied Codex
project hooks from the updated plugin after approval and start a new session.
For Claude, review the `enable-auto-save` migration plan before applying it to an
existing vault. Existing vault Markdown is not recreated.

Jev stays optional: key registration is separate from project/vault consent.
Never paste keys into agent chat or command arguments. See the bundled Jev guide.

Agensi is a separate upload/review channel, not GitHub auto-sync. A GitHub release
or source merge does not mean an Agensi listing has been approved or updated.
